# Espace Propriétaires — Résidence

Application web privée destinée aux propriétaires de la résidence.

## Objectif

Permettre aux propriétaires :

- de s'identifier avec un code unique ;
- d'enregistrer leurs coordonnées ;
- d'indiquer leur disponibilité pour les réunions ;
- de proposer des sujets à discuter.

## Administration

Un espace administrateur permettra de gérer :

- les appartements ;
- les propriétaires ;
- les codes d'accès ;
- les réunions ;
- les participations.
